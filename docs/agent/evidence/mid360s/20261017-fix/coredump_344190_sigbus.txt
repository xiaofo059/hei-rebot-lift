解读：SDK 的**全局** `std::shared_ptr<spdlog::logger>`（`sdk_core/base/logging.cpp:27`）
在进程 exit handler 里析构；虚调用 `_M_dispose` 却解析到**系统** `libspdlog.so.1` 的实现，
而该 logger 对象由 SDK 内置 spdlog **1.3.1** 头文件代码构造 —— 布局/ABI 不一致 → SIGBUS。
同一缺陷在 PointCloud2 冒烟阶段表现为 SIGABRT `free(): invalid size`（coredump 309862/323545）。

复现（无硬件，Codex）：`dlopen` 系统 libspdlog(RTLD_GLOBAL) 后再 `dlopen` 原 SDK 并调用
`LivoxLidarSdkInit(nullptr,nullptr,nullptr)`（冻结源码先 InitLogger 后返回 false，不碰设备/套接字），
自然退出即 SIGBUS(-7)；单独加载原 SDK 则 exit 0。
